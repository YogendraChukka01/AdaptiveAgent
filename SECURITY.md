# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within AdaptiveAgent, please report it responsibly:

1. **Do NOT** open a public GitHub issue for security vulnerabilities
2. Email the maintainer at [TODO: your email] with details
3. Include steps to reproduce the vulnerability

## Scope

This policy applies to the AdaptiveAgent backend API, frontend, and infrastructure configuration.

## Security Features

AdaptiveAgent includes several built-in security measures:
- Prompt injection detection (Sunglasses library)
- Human-in-the-loop approval for high-risk actions
- 10-factor risk scoring model
- API key authentication
- Rate limiting

## Response

We will acknowledge receipt within 48 hours and provide an estimated timeline for a fix.
